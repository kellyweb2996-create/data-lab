# 데이터 탐구실

어떤 표 데이터든 넣으면 요약, 차트, 상관관계, 예측 모델까지 한 페이지에서 탐구할 수 있는 웹 도구입니다. 파일 하나(`index.html`)로 동작하고, 데이터는 브라우저 밖으로 나가지 않습니다.

## 기능

- **불러오기**: CSV, TSV, 엑셀(.xlsx), JSON 파일 열기 또는 끌어다 놓기, 시트에서 복사한 범위 붙여넣기. 한글 CSV(EUC-KR)도 자동 인식
- **개요**: 열마다 유형(숫자, 범주, 날짜) 자동 판별, 분포와 빈 칸 요약, 눈에 띄는 패턴 자동 발견
- **탐색**: 막대, 선, 산점도, 히스토그램, 상자 그림. 집계, 색으로 나누기, 필터, 숫자 표 복사
- **관계**: 숫자 열 상관 격자, 범주에 따른 차이(η²)
- **질문하기**: Claude가 데이터를 직접 집계해 답하고 차트를 그림 (claude.ai에서 열었을 때만 동작)
- **예측**: 선형 회귀와 결정 트리를 80:20으로 학습·평가, 중요한 입력, 값을 바꿔 보는 가정 시뮬레이션
- **표**: 검색, 정렬, 페이지 넘기기

## 사용법

`index.html`을 브라우저로 열면 됩니다. 처음에는 가상의 예시 데이터가 들어 있습니다.
