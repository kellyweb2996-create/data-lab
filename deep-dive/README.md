# DEEP DIVE — 3D 잠수함 보물 탐사

Three.js(ES 모듈)로 만든 브라우저용 수중 탐험 + 가벼운 생존 게임입니다.
해저에 흩어진 **보물 상자 10개**를 모두 찾은 뒤, 산소가 떨어지기 전에 **수면 기지**로 돌아오면 성공입니다.

빌드 도구 없이 동작하고, 물리 엔진도 쓰지 않습니다(관성·저항·부력을 직접 계산).
3D 모델·텍스처가 하나도 없어도 절차적으로 만든 대체 모델로 끝까지 플레이할 수 있습니다.

---

## 실행 방법

ES 모듈과 importmap을 쓰기 때문에 `index.html`을 더블클릭(file://)으로 열면 동작하지 않습니다. **로컬 서버**로 실행하세요.

```bash
cd deep-dive
python3 -m http.server 8000
```

또는 Node.js가 있다면:

```bash
npx serve .
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다.

> Three.js는 importmap을 통해 jsDelivr CDN(`three@0.170.0`)에서 불러오므로 **처음 실행할 때 인터넷 연결이 필요**합니다.
> 오프라인에서 쓰려면 `three` 패키지의 `build/three.module.js`와 `examples/jsm/` 폴더를 프로젝트 안에 복사한 뒤
> `index.html`의 importmap 경로를 그 위치로 바꾸면 됩니다.

## 조작키

| 키 | 동작 |
|---|---|
| **W / S** (↑ / ↓) | 전진 / 후진 (후진은 추력의 절반) |
| **A / D** (← / →) | 좌우 회전(yaw) |
| **Space** | 상승 (밸러스트 탱크 배수 — 천천히 가속) |

## 게임 규칙

- **산소**: 계속 줄어들며(가득 차 있을 때 약 3분 30초, 깊을수록 조금 더 빨리 소모) 0이 되면 실패합니다.
- **배터리**: 이동·상하 이동·탐조등에 쓰입니다. 0이 되면 탐조등이 꺼지고 최고 속도가 약 절반으로 떨어집니다.
- **선체 내구도**: 지형·바위·난파선과의 충돌(충격 속도에 비례), 상어의 공격(-15), 수압 때문에 줄어듭니다. 0이 되면 실패합니다.
- **수심 제한**: 90m부터 압력 경고가 뜨고, 100m보다 깊으면 선체가 서서히 손상됩니다. 동쪽 해구 바닥에 있는 보물 2개는 약 100~110m 깊이라 빠르게 다녀와야 합니다.
- **수면 기지**(레이더의 `B` 표시): 아래쪽에 들어가면 산소·배터리가 충전되고 선체가 수리됩니다. 상어는 기지 근처까지 쫓아오지 않습니다.
- **결과 화면**: 수집한 보물 수, 걸린 시간, 최대 수심을 보여 줍니다. 최고 기록은 `localStorage`(`deepDive.best`)에 저장됩니다.
  기록은 성공 여부 → 보물 수 → (성공한 경우) 더 짧은 시간 순으로 비교하고, 최대 수심 기록은 따로 저장합니다.

## 에셋 (선택 사항)

아래 경로에 파일을 넣으면 자동으로 사용하고, 없으면 대체 모델·텍스처로 전환합니다.
없는 파일 때문에 콘솔에 뜨는 404 오류는 정상입니다. 어떤 에셋이 적용됐는지는 콘솔의 `[DeepDive] 에셋 로드 결과`에서 확인할 수 있습니다.

| 경로 | 없을 때 대체 |
|---|---|
| `assets/models/submarine.glb` | 캡슐 + 원기둥 잠수함 (이름에 `prop`/`propeller`가 들어간 노드가 있으면 프로펠러로 회전) |
| `assets/models/fish/fish.glb`, `fish1.glb` ~ `fish3.glb` | 원뿔 물고기 (꼬리 흔들림 셰이더 포함) |
| `assets/models/shark.glb` (또는 `fish/shark.glb`) | 구·원뿔 조합 상어 (애니메이션 클립이 있으면 첫 번째 클립을 재생) |
| `assets/models/treasure.glb` | 상자 + 반원통 뚜껑 보물 상자 |
| `assets/models/shipwreck.glb` | 상자·원통 조합 난파선 |
| `assets/textures/sand/sand_03_diff_2k.jpg` (색상)<br>`sand_03_nor_gl_2k.jpg` (노멀, OpenGL 방식)<br>`sand_03_rough_2k.jpg` (거칠기) | 셰이더로 만든 절차적 모래 무늬(모래알 + 물결 요철) |

- 브라우저는 폴더 목록을 읽을 수 없어서 물고기 파일명은 `src/config.js`의 `assets.fish`에 나열해 두었습니다. 다른 이름을 쓰려면 여기에 추가하세요.
- 모델은 크기가 자동으로 맞춰지지만, **+Z 방향이 앞쪽**이라고 가정합니다.
- 물빛 일렁임(caustics)은 파일 없이 GLSL 셰이더(보로노이 노이즈 두 겹)로 실시간 생성합니다.

### 모래 텍스처 조절 (`src/Terrain.js` 맨 위 상수)

| 상수 | 기본값 | 의미 |
|---|---|---|
| `SAND_REPEAT` | 200 | 지형 한 변(640m)에 텍스처를 몇 번 반복할지. 200이면 한 장이 약 3.2m입니다. 모래알이 크게 보이면 값을 키우고, 너무 잘면 줄이세요. |
| `SAND_NORMAL_SCALE` | 1.0 | 노멀맵 요철 강도 |
| `SAND_MACRO_SCALE` | 0.27 | 타일링 깨기용 두 번째 샘플의 배율 (작을수록 큰 무늬) |
| `SAND_MACRO_MIX` | 0.45 | 두 번째 샘플이 섞이는 평균 비율 |

같은 텍스처를 원래 크기와 회전·확대한 크기로 두 번 샘플링하고, 위치마다 노이즈로 섞는 비율을 바꿔 반복 무늬가 티 나지 않게 했습니다.
diffuse만 sRGB, 노멀·거칠기 맵은 선형으로 읽고, anisotropy는 GPU 최대값을 씁니다.

### 후처리 조절 (`src/PostFX.js` 맨 위 상수)

`BLOOM_STRENGTH`·`BLOOM_RADIUS`·`BLOOM_THRESHOLD`(블룸), `VIGNETTE`(가장자리 어둡기), `EDGE_DISTORT`(가장자리 물결 왜곡).
렌더링 순서는 RenderPass → UnrealBloomPass → 수중 효과(왜곡·비네팅) → OutputPass(ACES 톤매핑, sRGB 출력)입니다.

## 파일 구조

```
deep-dive/
├── index.html          # HUD·시작/결과 화면 마크업, CSS, importmap
├── main.js             # 진입점
└── src/
    ├── config.js       # 밸런스·물리·에셋 경로 설정 (수치 조정은 여기서)
    ├── utils.js        # 심플렉스 노이즈, 시드 난수, 에셋 로더, 절차적 텍스처
    ├── Submarine.js    # 잠수함 모델 + 관성/저항/밸러스트 물리, 기울기, 프로펠러, 탐조등
    ├── Ocean.js        # 수심별 FogExp2·조명, 수면, 원뿔 god rays, 보로노이 caustics, 부유물·발광 플랑크톤·거품, 수면 기지
    ├── PostFX.js       # 후처리: 블룸, 비네팅, 가장자리 물결 왜곡, 톤매핑 출력
    ├── Terrain.js      # 노이즈 해저 지형, 모래 텍스처(타일링 깨기)·절차적 모래, 바위·산호·해초·난파선, 충돌용 높이
    ├── Treasures.js    # 보물 상자 배치·수집
    ├── FishSchool.js   # Boids 물고기 떼 (InstancedMesh, 180마리)
    ├── Shark.js        # 상어 순찰 → 추격 → 후퇴 상태 머신
    ├── Sonar.js        # 소나 파동 효과 + 표적 탐지
    ├── HUD.js          # 계기판, 경고, 원형 레이더, 화면 전환
    ├── AudioManager.js # Web Audio 실시간 합성 사운드
    └── Game.js         # 게임 루프, 입력, 카메라, 충돌, 생존 시스템, 기록 저장
```

## 물리 요약 (`Submarine.update`)

- 추력: `v += forward × thrust × dt`
- 밸러스트: `ballast`가 입력값(-1~1)을 향해 초당 0.55씩만 변하고, `v.y += ballast × 6 × dt` → 상승·하강이 천천히 붙습니다.
- 저항: 속도를 앞/옆/위 성분으로 나눠 `v ← v·exp(-(k + c|v|)·dt)` 를 적용합니다. 옆 방향 `k`가 커서 옆으로 잘 미끄러지지 않습니다(용골 효과).
- 회전: 각속도에도 감쇠가 있어서 키를 떼도 천천히 멈춥니다.
- 충돌: 앞·중앙·뒤의 구 3개로 지형 높이와 바위 충돌 구를 검사합니다. 밀어낸 뒤 법선 방향으로 반발(계수 0.5)시키고, 충격 속도가 1.2m/s를 넘으면 손상을 줍니다.

## 성능 메모

- 물고기·바위·산호·해초는 모두 `InstancedMesh`로 그립니다. Boids는 같은 무리 안에서만 이웃을 검사합니다.
- 부유물은 정점 셰이더에서 `mod()`로 카메라 주변에 반복 배치해 CPU 비용이 없습니다.
- 픽셀 비율은 최대 1.75로 제한하고, 프레임이 떨어져도 물리가 튀지 않도록 `dt`를 0.05초로 제한합니다.
- 창 크기를 바꾸면 렌더러와 카메라 비율이 함께 조정되고, 좁은 화면에서는 HUD 배치가 바뀝니다.
